Верстка блока карточки товара и его описания.

Постарался слегка освежить, по моему мнению, визуал, сохранив основную цветовую гамму сайта.

При наведение на фото, появляются стрелки переключения слайдера. Если фото будет одно, то стрелки выводится не будут.
Ниже названия товара, перечислены его категории.
Кнопка "Узнать больше" ведет на блок с описанием товара.
При переключение фасовки, меняется: артикул, цена, старая цена.
При нажатии на кнопку "В корзину", появляется кнопка "Перейти в корзину", которая будет вести в корзину.
Блок описания товара сделан также вкладками.

Чтобы открыть верстку на компьютере
1. Скачайте архив
2. Распакуйте архив
3. Файл index.html откройте через браузер
